# Certified topic badges on tutor cards

The learner tutor browser receives certification counts but not topic names.
Return the already-selected CERTIFIED subject/topic pairs in the API response
and render them with the existing verified TopicChip used on tutor profiles.

Show up to three topic badges plus the remaining count. Keep subject and class
badges, anonymous identity rules and tutor-profile links. Let cards grow beyond
their minimum height so long topics and metadata do not clip.

Verify the API includes certified pairs, cards show topics even without verified
published classes, and additional topics have an accurate overflow count.
