# Katuwang Docs

| Path | What it is |
|---|---|
| [`plans/`](./plans/) | Implementation plans — active and historical. See [`plans/README.md`](./plans/README.md) for the index and status of each. |
| [`roles/`](./roles/) | Per-role feature + API reference: [`LEARNER.md`](./roles/LEARNER.md), [`TUTOR.md`](./roles/TUTOR.md), [`ADMIN.md`](./roles/ADMIN.md). |
| [`reference/`](./reference/) | Standing reference: [`auth-implementation.md`](./reference/auth-implementation.md) (registration & login build guide), [`theme.md`](./reference/theme.md) (DaisyUI OKLCH tokens). |
| [`erd.md`](./erd.md) | Auto-generated Prisma ERD for the current schema (regenerated by `prisma-erd-generator` on `npx prisma generate`). |
| `TODO.txt` | Flat UI/UX + feature backlog (the source list the todo-cleanup sprint plan chunked up). |
| `TOTEST.txt` | Ad-hoc manual-test scratchpad. |
| `feature-status-and-sprint-report.xlsx` | Sprint / feature status spreadsheet. |

> `prisma/schema.prisma` is the source of truth for the data model; `erd.md` is its rendered view. There is no separate hand-maintained schema doc.
