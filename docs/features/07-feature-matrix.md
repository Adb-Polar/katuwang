# Feature matrix

**Yes/Own:** role can perform the documented action within its scope. **Public:** available without authentication as well. **Affected/System:** behavior applies through system logic, not a new user permission. **Context/Operator:** see development/operator guards; these are not extra roles. A dash means no corresponding role-specific capability. Admin does not inherit Tutor/Learner permissions.

Each row links to a full feature specification; grouped CRUD actions are enumerated in that specification and the method reference.
