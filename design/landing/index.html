Ten directions for /

Static HTML prototypes sharing the live theme tokens and fonts (Apfel Grotezk + Fragment Mono; teal / ube / marigold). Each takes a different bet on the hero and page rhythm. Sample IDs and numbers are fictional.

Every prototype keeps the invariants: IDs always carry STU-/TUT-; violet = learner, gold = tutor; no payments, no fake stats, help assistant is rule-based (not “AI”). Prototype 05 is dark, which the live theme does not currently support.
