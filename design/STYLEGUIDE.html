8 · Accessibility — fixed boundaries

  • Visible focus on every interactive element: 2px green outline, inputs add a 3px ring. Never removed.
  • Semantic HTML first — real button, a, table, details, label, fieldset/legend. ARIA only where native can't express it.
  • Every colour also carries a text/code/glyph cue (§2–3). Verify greyscale and colour-blind rendering.
  • Contrast target 4.5:1 at shipped sizes — badge text on its tint, muted text on surface, green nav-pill text, white on --brand.
  • Keyboard: sidebar <details>, ⋯ menus, row actions, dialogs fully operable; dialog traps focus while open, restores on close.
  • Preserve input across validation errors, network failures, dismissal, navigation.
  • Respect prefers-reduced-motion. Tables scroll inside .table-wrap; the body never scrolls sideways.

9 · Invariants & allowed variation

Fixed

  • Fragment Mono = notation, Apfel Grotezk = speech.
  • Identity vs. state colour families, never mixed. Brand teal ≠ success green.
  • Every colour + a non-colour cue.
  • Card shell, grouped sidebar, sticky top bar, pill badges.
  • Radius .625 / 1rem; pill on badges/search/avatar.
  • No SVG icons — letter-tiles / glyphs only.

Free to vary

  • Card contents, grid (.grid-2/3), counts.
  • Which letter fills an .ic/.tile.
  • New status codes on an existing state tint.
  • Colour-token lightness/chroma for contrast; shadow depth.
  • Dark-theme values; chart type.

Reopen the direction only for new subject evidence, cultural harm, an unsolvable accessibility failure, a changed product need, or an explicit user override. Log it in PRODUCTION-BASELINE.md (two reopens already recorded there).
